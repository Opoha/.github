# Contributing to Opoha

Thanks for helping improve Opoha.

## Ground rules

- Multi-repo ecosystem: [github.com/Opoha](https://github.com/Opoha)
- Core never depends on `@opoha/plugin-*` or provider SDKs
- Never commit secrets (`.env`, credentials, private keys) — use `.env.example` only
- Prefer focused PRs; search issues before opening new ones

## Start here

```bash
npx @opoha/create-opoha@latest my-store --yes --preset commerce
```

Architecture and roadmap: [opoha-workspace](https://github.com/Opoha/opoha-workspace).
