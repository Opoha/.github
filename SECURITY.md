# Security Policy

## Supported versions

Security fixes are applied to the latest published releases of official Opoha packages under [github.com/Opoha](https://github.com/Opoha) (for example `@opoha/core`, `@opoha/cli`, `@opoha/create-opoha`, and certified plugins).

Older major lines may not receive patches unless a release is still marked supported in that repository’s README or release notes.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Prefer one of:

1. **GitHub private vulnerability reporting** on the affected repository (Security → Report a vulnerability), when enabled.
2. Email **security@opoha.dev** with a clear description, impact, and steps to reproduce (or a proof-of-concept that does not exploit third parties).

Include package names, versions, and environment details when possible.

## What to expect

- We aim to acknowledge reports within **7 days**.
- We will coordinate a fix and disclosure timeline; please give us reasonable time before public discussion.
- Credit is offered for valid reports unless you prefer anonymity.

## Non-security bugs

Use the normal issue templates and [CONTRIBUTING](./CONTRIBUTING.md) for non-security bugs and feature requests.
