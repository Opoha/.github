# Opoha/.github

Organization profile and shared GitHub metadata for [Opoha](https://github.com/Opoha).

| Path | Purpose |
| --- | --- |
| [`profile/README.md`](./profile/README.md) | Org landing page |
| [`CONTRIBUTING.md`](./CONTRIBUTING.md) | Default contribution guidelines for the org |
| [`ISSUE_TEMPLATE/`](./ISSUE_TEMPLATE/) | Default bug / feature issue forms |

Repositories may also ship their own `CONTRIBUTING.md` / `LICENSE` (MIT across Opoha packages).
